## 📖 The Story

Seven months somehow became a little world of their own. From the "Daddu Era" and misunderstandings to handmade gifts, sweet Kolkata moments, and growing closer through every conversation.

### ✨ Chapters
1. **Chapter 01: The Daddu Era** — A playful throwback to snooty chats, early banter, and poking Daddu.
2. **Chapter 02: The Misunderstanding** — Fragmentation mended with Japanese Kintsugi golden veins.
3. **Chapter 03: Dudu Unlocked (Handmade Gifts)** — 3D gift box revealing the embroidered handkerchief, crochet heart keychain, and 28 cards deck.
4. **Chapter 04: The Naraz Bubu** — Interactive naraz meter and pacification mini-game.
5. **Chapter 05: Oh... You're Actually Caring** — Discovering the protective, deeply caring side of Dudu with interactive heartbeat sound.
6. **Chapter 06: A Little Piece of Kolkata** — Solo journey bringing back authentic Kolkata gulab jamun and homemade chiwda.
7. **Chapter 07: Still Us** — Sunset twilight, memory pills, and connected fate threads.
8. **Final Reveal: A Letter From Bubu** — Heartfelt parchment letter, interactive heart sparkles, and our keepsake Polaroid photo frame.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 5
- **Styling**: Tailwind CSS (custom warm cream, ivory, burgundy, gold & rose palette)
- **3D Graphics**: Three.js (interactive 3D parallax particle background)
- **Animations**: Framer Motion (page transitions, 3D tilt cards, scrapbook unfolds)
- **Audio**: Web Audio API (procedural romantic ambient piano chime, paper unseal, heartbeats, and celebration chimes)
- **Interactive FX**: Canvas Confetti
- **Icons**: Lucide React

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Abhilash-ai/7-months-of-US.git

# Enter directory
cd 7-months-of-US

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
